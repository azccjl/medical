# 地图优化与站点标定计划（2026-10-11）

比赛规则图和现场照片一致：场地为 4.5 m × 4.5 m，体检区窗口为 A、B、C，化验区窗口为 1、2、3、4。识别板一位于右下起点附近，识别板二位于左上。规则和照片没有 D 标志，因此暂不为 D 编造坐标。

`medical-live-map-20261010.pgm` 是原始导航候选地图，保留不改。5 cm 栅格放大后出现台阶属于栅格显示效果；右下显示器的非规则轮廓属于真实障碍，应保留。已生成双线性放大的 `medical-live-map-smooth-preview.png`，它只改善显示，不改变占用栅格。

把墙线直接画直或用滤波器强行抹平会改变障碍位置，可能让规划器把真实挡板当成可通行区域。因此在导航验收前不替换原 PGM。

`site-waypoints-diagram-estimate.json` 根据官方示意图把 1、2、3、4、A、B、C、识别板一、识别板二和起点投影到当前地图坐标。它的状态是 `DIAGRAM_ESTIMATE_ONLY`，不是可直接导航的坐标；每个点还没有实地测量的停车中心和进站朝向。

正式标定顺序：起点 → 识别板一 → A/B/C → 识别板二 → 1/2/3/4。用 RViz 记录每个窗口中心和朝向；实测时要求车身完全进入方框并停留 1–2 秒。窗口坐标确定后再写入导航 YAML，先做单点低速定位，再做无载短路径，最后接入自主任务队列。
