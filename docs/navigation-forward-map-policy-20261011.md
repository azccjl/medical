## 当前结论

后方车载平台造成的回波不需要作为前进方向的实时障碍检查。已完成一个候选策略：

- 规划前先用完整地图检查整车 footprint 和路线余量；地图未知区域仍阻止路线。
- 行驶中只检查前方和转弯侧原始 `/scan`，后方回波不触发前进拒绝。
- 后方和被车体遮挡区域不会被改写成自由空间；原始 `/scan`、`/medical_slam_scan` 和定位输入不变。
- 当前向量过滤只给 costmap 候选话题，不直接连接底盘。

这解决了“后方不必参与前进判断”的软件方向，但不等于已经通过现场导航验收。

## 建议的一次性综合流程

小车准备好后，不再拆成多个小动作：放回起点并停稳 → 启动传感器/AMCL/前向过滤 → 连续采集静止定位 → 低速直行、连续左转、连续外圈路线，同时记录所有审计和物理观察 → 自动停车并生成综合报告。任一安全条件失败就停在零速并保留证据。

这套流程开始前会明确告诉你预计路线、最大速度、前方空间和断电位置；在车不在场地时不会启动。
